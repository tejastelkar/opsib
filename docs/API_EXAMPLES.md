# API examples

Generated by `scripts/capture_api_examples.py` from real requests against the application (fixture pack, frozen clock 2026-10-16T15:00:00+05:30). IDs other than exception IDs differ between runs. Timestamps in responses are UTC. See [API.md](API.md) for the contract and `openapi.json` for the schema.

## Imports
Each dataset is uploaded as a CSV file. Row-level outcomes are in the response.
